# todo-manager-python
Simple TODO manager written in Python.
 TODO Manager

A simple TODO manager written in Python.

## Features

- Add tasks
- Show tasks
- Mark tasks as completed
- Delete tasks
- Save tasks to a text file
- Load tasks automatically on startup

## Technologies

- Python 3

## How to run

```bash
python todo_manager.py
```
## PS

For now, to ensure the program runs correctly, you need to create a `tasks.txt` file, as I haven't yet implemented error handling.
